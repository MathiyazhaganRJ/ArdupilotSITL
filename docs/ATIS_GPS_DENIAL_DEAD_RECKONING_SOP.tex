{\normalsize\raggedright Simulates physical antenna severance or receiver power cutoff. SITL instantly sets \texttt{fix\_type = 0} (NO\_FIX) and \texttt{satellites\_visible = 0}. \textbf{LSK 2L COMMAND:} {\bfseries\normalsize\color{avcyan}param set SIM\_GPS1\_JAM 1} \\[1mm]
{\normalsize\raggedright Injects broadband RF interference on GPS L1/L2 carrier frequencies (\texttt{C/N0 < 28 dB-Hz}), inflating pseudorange noise. \textbf{CAUTION:} SITL maintains a degraded 3D fix with jumping coordinates; requires automated gating configuration (Section 2) to eliminate aircraft wandering.\par}

\textbf{2. INNOVATION GATING \& ATTITUDE HORIZON PROTECTION}

\begin{tcolorbox}[colback=avboxbg,colframe=avborder,arc=1mm,boxrule=0.5pt,top=1.5mm,bottom=1.5mm,left=3mm,right=3mm]
\textbf{\large\color{avdark}EK3\_GLITCH\_RAD} \hfill \textbf{\small\color{avgray}[INNOVATION STEP GATE THRESHOLD]} \\
\textbf{DEFAULT:} \texttt{25.0} m \hfill \textbf{RECOMMENDED:} {\color{avgreen}\texttt{15.0} to \texttt{20.0} m} \\
\textbf{MCDU COMMAND:} {\bfseries\normalsize\color{avcyan}param set EK3\_GLITCH\_RAD 15} \\[1mm]

\begin{tcolorbox}[colback=avboxbg,colframe=avborder,arc=1mm,boxrule=0.5pt,top=1.5mm,bottom=1.5mm,left=3mm,right=3mm]

\textbf{MCDU COMMAND:} {\bfseries\normalsize\color{avcyan}param set FS\_EKF\_THRESH 0.60} \\[1mm]
{\normalsize\raggedright Normalized innovation variance ratio that triggers autonomous EKF Failsafe. Lowering to \texttt{0.60} forces ArduPlane to trip failsafe immediately under jamming noise rather than tolerating noisy jumping fixes.\par}

\begin{tcolorbox}[colback=avboxbg,colframe=avborder,arc=1mm,boxrule=0.5pt,top=1.5mm,bottom=1.5mm,left=3mm,right=3mm]

\noindent\textbf{3. DEAD RECKONING \& AERODYNAMIC WIND ESTIMATION}

\begin{tcolorbox}[colback=avboxbg,colframe=avborder,arc=1mm,boxrule=0.5pt,top=1.5mm,bottom=1.5mm,left=3mm,right=3mm]
\textbf{\large\color{avdark}EK3\_DRAG\_BCOEF\_X / EK3\_DRAG\_BCOEF\_Y} \hfill \textbf{\small\color{avgray}[DRAG BALLISTICS]} \\
\textbf{DEFAULT:} \texttt{0.0} (DISABLED) \hfill \textbf{AIRFRAME TARGET:} {\color{avgreen}\texttt{25.0} to \texttt{35.0} ($kg/m^2$)} \\
\textbf{LSK 4L COMMANDS:} {\bfseries\normalsize\color{avcyan}param set EK3\_DRAG\_BCOEF\_X 25} \quad|\quad {\bfseries\normalsize\color{avcyan}param set EK3\_DRAG\_BCOEF\_Y 25} \\[1mm]
{\normalsize\raggedright Calibrates longitudinal and lateral airframe ballistic drag. In GPS-denied flight, EKF3 combines pitot true airspeed ($V_{\text{tas}}$) with accelerometer drag deceleration to estimate horizontal wind ($\vec{W}$), synthesizing ground track: $\vec{V}_{\text{ground}} = \vec{V}_{\text{air}} + \vec{W}$.\par}
\end{tcolorbox}

\begin{tcolorbox}[colback=avboxbg,colframe=avborder,arc=1mm,boxrule=0.5pt,top=1.5mm,bottom=1.5mm,left=3mm,right=3mm]
\textbf{\large\color{avdark}EK3\_SRC\_OPTIONS} \hfill \textbf{\small\color{avgray}[SENSOR FALLBACK CASCADE BITMASK]} \\
\textbf{DEFAULT:} \texttt{0} (MANUAL FALLBACK) \hfill \textbf{AUTONOMOUS TARGET:} {\color{avgreen}\texttt{1} (AUTO FALLBACK)} \\
\textbf{LSK 5L COMMAND:} {\bfseries\normalsize\color{avcyan}param set EK3\_SRC\_OPTIONS 1} \\[1mm]
{\normalsize\raggedright Enables automatic sensor cascade. Setting Bit 0 allows EKF3 to drop an unhealthy GPS autonomously and switch to Dead Reckoning or Optical Flow without pilot intervention.\par}
\end{tcolorbox}
